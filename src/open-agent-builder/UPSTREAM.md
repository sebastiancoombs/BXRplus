# Firecrawl Open Agent Builder

This native BXR+ integration is adapted from
[`firecrawl/open-agent-builder`](https://github.com/firecrawl/open-agent-builder)
at commit `be856e57f8126e90915c898f473dc94fbaefc945`.

The upstream project describes itself as MIT-licensed in its README. Its
Clerk authentication, Convex persistence, marketing shell, and standalone
Next.js routes were intentionally not copied. BXR+ already provides
authentication and the integrated canvas persists drafts locally.
